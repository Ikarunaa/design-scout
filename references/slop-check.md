# Slop check

Run this against the finished build. These are the tells that make a site read as generic or machine-made. None is forbidden on its own: any of them is fine when the brief chose it on purpose, with a reference behind it. The problem is when they appear by default, because nobody decided otherwise.

For each one present, ask: is this in the brief? If not, replace it with what the brief says.

## Layout
- Centred headline, centred subhead, two buttons, then a row of three equal cards with an icon on top
- Every section the same shape: heading, paragraph, grid, repeat
- Everything in rounded cards with a soft shadow, same radius everywhere
- No variation in scale: nothing is very big, nothing is very small
- Perfectly even spacing with no rhythm, so nothing groups or leads the eye
- Mobile is the desktop layout stacked, with no decisions made for a small screen

## Colour
- Purple-to-blue or indigo-to-pink gradient as the main visual idea
- Gradient text on the headline
- Blurred colour blobs behind the hero
- Pure white or near-black background with one saturated accent and nothing else
- Dark mode with neon glow, for a business with no reason to be dark

## Type
- One default sans (Inter, system UI) for everything, at safe middle weights
- Headline and body too close in size to create hierarchy
- Centre-aligned body paragraphs
- A small uppercase letter-spaced label above every single heading

## Content
- Headlines that fit any company: "Elevate", "Unlock", "Seamless", "Supercharge", "Reimagine", "All-in-one platform"
- Emoji used as icons or as bullet markers
- Feature lists of abstract nouns (Fast, Secure, Scalable) with no specifics
- Invented testimonials, names, logos, star ratings or numbers. These must never ship: use marked placeholders
- Stock-style images of people at laptops, or AI-looking illustrations, standing in for real product or real work
- Lorem ipsum or obvious filler left in

## Detail
- Glass-blur panels for no functional reason
- Identical hover effect on everything (lift and shadow)
- Fade-up-on-scroll on every element
- Icon set mixed from different families, or generic line icons where a real image would say more
- Footer is a default four-column link grid for a site with five links

## The positive test

Passing the list above only removes the worst. Then check the good side:

- Can you point to the signature element from the brief on the page, built as described?
- Cover the logo: could you still tell which business this is, or what kind?
- Does each section trace back to a decision in the brief?
- Put a screenshot next to the references you kept. Does it belong in that company, without being a copy of any one of them?
- Is there one thing here a visitor would mention to someone else?
